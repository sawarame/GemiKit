### **Name**
GemiKit

### **Short Description**
Enhance your Google Gemini web interface. Download chats as Markdown, type newlines with Enter, and send messages with Ctrl+Enter.

### **Detailed Description**
[ PURPOSE ]
GemiKit is a lightweight browser extension designed to improve your text input experience and productivity on the Google Gemini web interface. It prevents accidental message submissions by modifying the default behavior of the Enter key, and allows you to easily export your chat history as clean Markdown files.

[ CORE FEATURES ]
- Markdown Export: Download your chat history with Gemini in a clean Markdown format. Unwanted UI elements like avatars and prompt boxes are automatically excluded.
- Newline on Enter: Pressing the Enter key will insert a newline instead of immediately sending the message.
- Shortcut to Send: Use Ctrl + Enter (or Cmd + Enter on Mac) to securely submit your prompts.
- Floating Toolbox: Access all features conveniently from a floating action button at the bottom right of the screen.
- Toggle Functionality: The entire extension can be easily enabled or disabled via the floating toolbox or the extension options page.
- Reliable UI Hooking: Built to seamlessly integrate with the latest Gemini user interface, including Web Components and Shadow DOM elements.

[ DISTINCTIVE FEATURES ]
Unlike standard input fields that force you to adapt, GemiKit adapts the interface to standard text editor behaviors, ensuring you never send an incomplete prompt by mistake, while adding powerful export capabilities to save your conversations.

[ HOW TO USE ]
1. Install the extension.
2. Open or reload the Google Gemini web interface.
3. Access the floating toolbox at the bottom right to download chat history or manage settings.
4. Type your prompt in the chat box. Press Enter to create new lines.
5. When you are ready to submit, press Ctrl + Enter or Cmd + Enter.
6. To revert to the default behavior, toggle GemiKit off from the toolbox or extension menu.

[ PRIVACY FIRST ]
GemiKit operates entirely within your browser. It does not collect, store, or transmit any of your personal data or chat history. The extension only requires minimal permissions necessary to save your toggle preferences locally.

### **名前**
GemiKit

### **短い説明**
Google Geminiの体験を向上させます。チャット履歴のMarkdown形式での保存、Enterキーでの改行、Ctrl+Enterでの確実な送信をサポートします。

### **詳細説明**
【 目的 】
GemiKitは、Google Geminiウェブインターフェースでのテキスト入力体験と生産性を向上させるための軽量なブラウザ拡張機能です。Enterキーのデフォルトの挙動を変更することで誤送信を防ぎ、チャット履歴を綺麗なMarkdown形式で簡単にエクスポートできるようにします。

【 主な機能 】
・ Markdownエクスポート: チャット履歴をクリーンなMarkdown形式でダウンロードできます。アバターやプロンプト入力欄などの不要なUI要素は自動的に除外されます。
・ エンターキーによる改行: 入力欄でEnterキーを押下した際、メッセージを送信せずに改行を挿入します。
・ ショートカット送信: メッセージの送信はCtrl + Enter（Macの場合はCmd + Enter）に割り当てられ、意図しない送信を確実に防止します。
・ フローティングツールボックス: 画面右下のフローティングボタンから、いつでも手軽に機能へアクセスできます。
・ 機能の切り替え: ツールボックスやオプション画面から、GemiKit全体の有効/無効を簡単に切り替えることができます。
・ 最新UIへの対応: Gemini側のUIアップデートやShadow DOMコンポーネントにも適切に対応し、安定して動作します。

【 特徴的な機能 】
誤って作成途中のプロンプトを送信してしまうストレスを排除し、一般的なテキストエディタと同様の直感的な操作感を提供します。さらに、対話内容を綺麗に保存できる強力なエクスポート機能を追加します。

【 使用方法 】
1. 拡張機能をインストールします。
2. Google Geminiのページを開く、または再読み込みします。
3. 画面右下のフローティングツールボックスから、チャット履歴のダウンロードや設定の管理を行えます。
4. チャット入力欄でテキストを入力し、Enterキーで改行を行います。
5. 送信の準備ができたら、Ctrl + Enter または Cmd + Enter を押下して送信します。
6. デフォルトの挙動に戻したい場合は、ツールボックスや拡張機能アイコンから機能をオフにしてください。

【 プライバシー最優先 】
GemiKitはブラウザ内で完結して動作します。ユーザーの個人情報やチャット履歴を収集、保存、または外部へ送信することは一切ありません。ローカルに設定を保存するための最小限の権限のみを使用しています。

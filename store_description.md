### **Name**
GemiKit

### **Short Description**
Enhance your Google Gemini web interface. Type newlines with Enter and send messages confidently with Ctrl+Enter or Cmd+Enter.

### **Detailed Description**
[ PURPOSE ]
GemiKit is a lightweight browser extension designed to improve your text input experience on the Google Gemini web interface. It prevents accidental message submissions by modifying the default behavior of the Enter key, allowing you to insert newlines naturally while chatting.

[ CORE FEATURES ]
- Newline on Enter: Pressing the Enter key will insert a newline instead of immediately sending the message.
- Shortcut to Send: Use Ctrl + Enter (or Cmd + Enter on Mac) to securely submit your prompts.
- Toggle Functionality: The custom behavior can be easily turned on or off via the extension options page.
- Reliable UI Hooking: Built to seamlessly integrate with the latest Gemini user interface, including Web Components and Shadow DOM elements.

[ DISTINCTIVE FEATURES ]
Unlike standard input fields that force you to adapt, GemiKit adapts the interface to standard text editor behaviors, ensuring you never send an incomplete prompt by mistake.

[ HOW TO USE ]
1. Install the extension.
2. Open or reload the Google Gemini web interface.
3. Type your prompt in the chat box. Press Enter to create new lines.
4. When you are ready to submit, press Ctrl + Enter or Cmd + Enter.
5. To revert to the default behavior, click the extension icon and toggle the setting off in the options menu.

[ PRIVACY FIRST ]
GemiKit operates entirely within your browser. It does not collect, store, or transmit any of your personal data or chat history. The extension only requires minimal permissions necessary to save your toggle preferences locally.

### **名前**
GemiKit

### **短い説明**
Google Geminiの入力体験を向上させます。Enterキーで改行を行い、Ctrl+EnterやCmd+Enterで確実にメッセージを送信します。

### **詳細説明**
【 目的 】
GemiKitは、Google Geminiウェブインターフェースでのテキスト入力体験を向上させるための軽量なブラウザ拡張機能です。Enterキーのデフォルトの挙動を変更することで誤送信を防ぎ、自然な改行入力を可能にします。

【 主な機能 】
・ エンターキーによる改行: 入力欄でEnterキーを押下した際、メッセージを送信せずに改行を挿入します。
・ ショートカット送信: メッセージの送信はCtrl + Enter（Macの場合はCmd + Enter）に割り当てられ、意図しない送信を確実に防止します。
・ 機能の切り替え: 拡張機能のオプション画面から、この機能の有効/無効をいつでも切り替えることができます。
・ 最新UIへの対応: Gemini側のUIアップデートやShadow DOMコンポーネントにも適切に対応し、安定して動作します。

【 特徴的な機能 】
誤って作成途中のプロンプトを送信してしまうストレスを排除し、一般的なテキストエディタと同様の直感的な操作感を提供します。

【 使用方法 】
1. 拡張機能をインストールします。
2. Google Geminiのページを開く、または再読み込みします。
3. チャット入力欄でテキストを入力し、Enterキーで改行を行います。
4. 送信の準備ができたら、Ctrl + Enter または Cmd + Enter を押下して送信します。
5. デフォルトの挙動に戻したい場合は、拡張機能アイコンから設定画面を開き、機能をオフにしてください。

【 プライバシー最優先 】
GemiKitはブラウザ内で完結して動作します。ユーザーの個人情報やチャット履歴を収集、保存、または外部へ送信することは一切ありません。ローカルに設定を保存するための最小限の権限のみを使用しています。

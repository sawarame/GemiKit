# GemiKit (旧 Gemini Spark) 仕様書

## プロジェクトの目的
Google Gemini のウェブインターフェースでの入力体験と生産性を向上させるためのブラウザ拡張機能。意図しない送信を防ぎ快適な改行入力を提供するほか、チャット履歴を綺麗なMarkdown形式で簡単にエクスポート可能にする。

## 主な機能
- **エンターキーによる改行**: チャット入力欄で `Enter` キーを押下した際、メッセージを送信せずに改行を挿入する。
- **ショートカット送信**: メッセージの送信は `Ctrl + Enter` (Macの場合は `Cmd + Enter`) に割り当て、誤送信を防止する。
- **Markdownエクスポート**: 画面右下のフローティングツールボックスから、チャット履歴をMarkdown形式でダウンロード可能。
  - アバター画像、プロンプト入力用のテキストエリア、Geminiの注意書き等の不要な要素は除外される。
  - チャット履歴が存在しない新規チャット画面ではボタンが非活性化される。
- **フローティングツールボックス**: 画面右下に常時表示されるボタンをホバーすることでメニューが展開し、機能へ簡単にアクセスできる。
- **機能のON/OFF切り替え**: ツールボックス内または拡張機能のオプション画面から、GemiKit全体の機能の有効/無効をいつでも切り替え可能。
- **多言語対応 (i18n)**: 英語と日本語のローカライズに対応（設定画面および拡張機能情報）。
- **最新UI対応**: Gemini側のUI変更やShadow DOMにも対応し、入力エリアや送信ボタンを正確にフックして動作する。

## 使用技術・構成
- **言語**: TypeScript / HTML / CSS
- **外部ライブラリ**: `turndown`, `turndown-plugin-gfm` (Markdown変換用)
- **アイコン**: SVGから `sharp` を用いて各種サイズのPNGアイコンを自動生成（ツールボックスをモチーフにしたデザイン）
- **ビルド**: `tsc` によるコンパイル後、`package` フォルダとして拡張機能用ファイル一式をビルドし、Zip化
- **CI/CD**: 
  - `manifest.json` のバージョンに基づく GitHub Actions によるリリース自動生成
  - `chrome-webstore-upload-cli` を用いたChromeウェブストアへの自動公開（GitHub Release時および手動実行に対応）
